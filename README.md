# 🛍️ ShopSense AI — E-commerce Support Agent

An AI-powered customer support system that handles order status, delivery tracking, and product queries in real time — without a human agent in the loop. Built as a multi-agent system with a database-connected sub-agent, a FastAPI backend, and an animated Streamlit chat UI.

---

## ✨ What It Does

When a customer asks about an order's status, tracking number, delivery date, or a product, the agent autonomously writes a SQL query, pulls live data from the database, and replies in a natural, friendly tone. Greetings, return-policy questions, and general FAQs are answered directly from the agent's own knowledge — the database is only queried when real data is actually needed.

---

## 🧠 Tech Stack

| Layer | Technology | Purpose |
|---|---|---|
| **Agent orchestration** | **LangGraph** (via DeepAgents) | Builds the multi-agent graph — a supervisor agent that routes conversation, and a specialized sub-agent for database lookups |
| **LLM** | **Groq** (`openai/gpt-oss-120b`) via LangChain | Powers reasoning, conversation, and tool-calling decisions |
| **Database access** | **MCP Toolbox for Databases** | Exposes the SQLite `orders` database as a controlled tool via the Model Context Protocol — restricted to `SELECT` only, no INSERT/UPDATE/DELETE |
| **Backend API** | **FastAPI** | Serves a `/chat` endpoint that receives user messages and returns agent responses |
| **Data validation** | **Pydantic** | Defines and validates the `/chat` request schema (`text`, `thread_id`), giving FastAPI automatic input validation and auto-generated API docs |
| **Frontend** | **Streamlit** | A custom animated chat UI — glassmorphism design, gradient background, typing indicator, quick-action buttons, and live session stats |
| **Database** | **SQLite** | Stores order records: order ID, customer, product, quantity, price, status, dates, tracking number |

---

## 🏗️ Architecture

```
User (Streamlit UI)
        │
        ▼
   FastAPI  /chat  (validated by Pydantic ChatRequest)
        │
        ▼
  Supervisor Agent (LangGraph / DeepAgents)
        │
        ├── Greetings, FAQs, policies → answered directly
        │
        └── Order / tracking / product questions
                    │
                    ▼
          order_support_agent (sub-agent)
                    │
                    ▼
          query_database_tool
                    │
                    ▼
        MCP Toolbox for Databases  →  orders.db (SQLite)
```

Conversation memory is preserved per session using LangGraph's `MemorySaver` checkpointer, keyed by `thread_id`.

## ⚙️ Setup & Installation

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd <repo-folder>
```

### 2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Set up environment variables
Create a `.env` file in the project root with your Groq API key:
```
GROQ_API_KEY=your_groq_api_key_here
```

### 5. Generate the database
```bash
python database.py
```

### 6. Start the MCP Toolbox server
Download and run the [MCP Toolbox for Databases](https://github.com/googleapis/genai-toolbox) binary, pointing it at `tools.yaml`:
```bash
./toolbox --tools-file "tools.yaml"
```
This starts the toolbox server on `http://127.0.0.1:5000` by default.

### 7. Start the backend
```bash
uvicorn agent:app --reload --port 8000
```

### 8. Start the frontend
```bash
streamlit run app.py
```

## 🔒 Safety Notes

- The database tool is restricted to `SELECT` statements only — no data can be modified through the agent.
- Optional human-in-the-loop approval is configured (`interrupt_on`) so database queries can require manual approval before execution.
- `.env` and other secrets are excluded from version control via `.gitignore`.
